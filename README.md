# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг

## Структура модулей
- `main.py` точка входа и пользовательский интерфейс
- `storage.py` чтение, запись и управление данными в JSON
- `stats.py` расчёт средней оценки и статистики по авторам
- `models.py` класс Book

## Как запустить
python main.py

## Пример работы
1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход
